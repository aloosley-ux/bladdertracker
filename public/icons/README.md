# App Icon & Splash Screen Assets

Drop generated icon and splash screen assets into this folder.
See `ASSETS_REQUIRED.md` in the project root for exact dimensions,
file names, and platform-specific folder paths.

## Quick start

1. Create a 1024×1024 master icon (PNG, no rounded corners)
2. Create a 600×600 splash logo (PNG, transparent background)
3. Use a generator like [appicon.co](https://appicon.co) to produce all sizes
4. Copy iOS assets into `ios/App/App/Assets.xcassets/`
5. Copy Android assets into `android/app/src/main/res/`
6. Keep master files here for reference
